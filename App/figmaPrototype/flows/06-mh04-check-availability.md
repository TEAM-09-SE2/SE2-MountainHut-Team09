# 06 - MH-04 Check availability

## User story

As a user, I want to check availability for date, time, and party size.

## Main frame

- Availability search page.

## UI structure

1. Quick form:
   - date
   - time
   - people
2. Results:
   - available slots
   - limited slots (warning)
   - full slots (disabled)
3. "Book this slot" CTA on available entries.

## Core components

- Search panel
- Slot list item
- Availability badge (available/limited/full)

## States

- No results
- Results loading
- Search error
