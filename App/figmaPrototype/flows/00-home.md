# 00 - Home

## Frame

- Desktop: 1440x1024
- Mobile: 390x844
- Grid: 12 columns desktop, 4 columns mobile

## Screen goal

Communicate the product value quickly and drive users to availability check or booking.

## UI structure

1. Top bar: logo, navigation, "Login" and "Register" actions.
2. Hero: headline, subtitle, primary CTA "Book now", secondary CTA "Check availability".
3. "How it works" section with 3 concise steps.
4. "Upcoming availability" cards (date, slot, seat summary).
5. Footer: hut contacts, legal links, social links.

## Core components

- Navbar
- Buttons (primary/secondary/ghost)
- Availability card
- Step card
- Footer links

## Main interactions

- Primary CTA -> MH-01 flow.
- Secondary CTA -> MH-04 flow.
- "Login" -> Login screen.
- "Register" -> Registration screen.

## Status states

- Availability loading
- Empty state (no slots available)
- Error state with retry action
