# 14 - MH-12 Monitor occupancy

## User story
As an employee, I want to see booked and remaining capacity for every slot.

## Screen goal
Provide a monitoring dashboard with fast anomaly detection.

## Key sections
1. Occupancy overview chart
2. Slot table (capacity, booked, remaining)
3. Alert lane for near-full/full slots
4. Quick actions to edit slot/capacity
