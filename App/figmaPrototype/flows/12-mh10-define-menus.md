# 12 - MH-10 Define menus

## User story
As an employee, I want to specify menus for defined slots so hikers know when service is provided.

## Screen goal
Create and publish slot-based menus with clear validity (date, slot, meal type).

## Key sections
1. Slot selector (date, meal time)
2. Menu composer (courses, dishes, notes)
3. Allergen and dietary tags
4. Publish controls and version history
