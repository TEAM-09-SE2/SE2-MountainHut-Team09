# 09 - MH-07 Reserve for hiker

## User story

As an employee, I want to enter a reservation for a hiker.

## Main frame

- Employee dashboard -> "Assisted booking".

## UI structure

1. Mode selection:
   - quick (name + optional phone)
   - full profile (full hiker details)
2. Booking details (date/time/party size/requirements).
3. Operator review and confirmation.

## Core components

- Mode segmented control
- Dynamic form
- "Created by operator" status badge

## Interactions

- Quick path optimized for desk/phone booking.
- Upgrade from quick to full before final confirmation.
